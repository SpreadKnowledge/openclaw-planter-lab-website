2026.09.12 抜根・観察完了／土壌分析へ発送

オクラを抜いてみたら根がびっしり

島オクラ2株を取り出し、土と根の最後の状態を記録しました。大小とも主茎は26節、長さは56cmと70cm。根の張り方と土の手触りを残し、培土300gを分析へ送りました。

OpenClawとは何か

OpenClawは、観察記録の整理、Markdown投稿の作成、静的サイトのビルド、差分確認などを支援するAIエージェントとして扱います。このサイトは、その保守フローを公開リポジトリで練習するための実験場です。

Demo Site GitHub Pagesで公開される静的サイト

公開対象は main ブランチの /docs フォルダです。

OpenClaw Planter Lab is a GitHub Pages demo maintained for OpenClaw website update practice.
