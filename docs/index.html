2026.08.31 曇天・水分保持

曇りの日はどうして水が減らない？

一日中曇って涼しかった日は、朝に散水した島オクラの土壌水分が日中も49.70％以上を保ちました。照度と気温を、水の減り方と一緒に振り返ります。

2026.08.30 着果停滞・原因を再検討

水を整えても実がつかないなら？

8月23日以降は土壌水分40％未満を避けられましたが、島オクラの新しい花蕾は確認できませんでした。水だけでなく、日射、株数、根域と作物選びから原因を見直します。

2026.08.27 有効雨の可能性・夜散水なし

屋根の下なのに雨が鉢まで届いた？

午後にまとまった雨が降り、追加散水なしで島オクラの土壌水分が47.12％から56.99％まで上昇しました。屋根下のプランターにも雨が届いた可能性が高いと判断し、夜の水やりは見送りました。

OpenClawとは何か

OpenClawは、観察記録の整理、Markdown投稿の作成、静的サイトのビルド、差分確認などを支援するAIエージェントとして扱います。このサイトは、その保守フローを公開リポジトリで練習するための実験場です。

Demo Site GitHub Pagesで公開される静的サイト

公開対象は main ブランチの /docs フォルダです。
